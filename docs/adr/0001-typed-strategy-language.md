# One typed strategy language with optional presets

The builder accepted a small composable typed language and optional template presets on 2026-10-03, Q4, followed by the amended operator and calculation decisions. Presets use the same language and validation boundary. This preserves adopted meaning while allowing combinations beyond fixed experiment templates. Separate template evaluators would make history, units and missing-value behavior diverge; unrestricted generated code would expand the proof and authority boundary.

The [specification](../superpowers/specs/2026-09-29-edge-os-hackathon-design.md#accepted-strategy-language-and-missing-data-policies) owns the required semantics. [Focused fixtures](../EDGE_OS_RESEARCH_CONTRACTS.md#typed-language-and-missing-data-acceptance-fixtures) are requirements, not executed evidence. Exact encoding, measured resource bounds and financial action qualification remain open. This accepted direction does not approve the full design or alter closed Probe A behavior.
