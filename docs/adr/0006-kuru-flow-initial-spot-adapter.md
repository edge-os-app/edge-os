# Start the spot adapter with Kuru Flow fixed-input swaps

The builder accepted Kuru Flow fixed-input swaps as the initial adapter direction on 2026-10-03, Q20 A, in [Exact Monad operation](../superpowers/specs/2026-09-29-edge-os-hackathon-design.md#exact-monad-operation). Bounded input and minimum received amount define the first controlled operation; a Kuru order-book adapter with resting orders and their lifecycle remains outside this slice. Flow routing and research-pool identity stay separate, even when a route uses a Kuru book.

The [existing Probe B](../prototypes/EDGE_OS_SCOPED_PROBE_PLAN.md#5-probe-b-delegated-monadkuru-action) must qualify the actual network, deployment/ABI, route, transaction restrictions, policy and transport. This records an initial direction, not cheaper/faster execution, guaranteed fills, full entry/exit qualification or financial approval.
