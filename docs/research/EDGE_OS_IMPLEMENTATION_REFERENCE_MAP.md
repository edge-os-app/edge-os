## Primary documentation for the selected stack

- [Privy access-token verification](https://docs.privy.io/authentication/user-authentication/access-tokens) and [token security requirements](https://docs.privy.io/authentication/user-authentication/tokens). Verify signature, issuer, audience, expiration and required owner identity. Token extraction or frontend login alone is insufficient. Use current docs to select and test actual key/rotation handling; do not copy a reference project's key assumptions automatically.
- [FastAPI security dependencies](https://fastapi.tiangolo.com/reference/security/) and [isolated dependency tests](https://fastapi.tiangolo.com/advanced/testing-dependencies/). A bearer extractor is not a cryptographic verifier. Test substitutions remain limited to test configuration.
- [Next.js styling](https://nextjs.org/docs/app/getting-started/css) and [Tailwind custom styles](https://tailwindcss.com/docs/adding-custom-styles). Preserve approved visual tokens and reusable styles. Choose compatible CSS/Tailwind based on the actual export, not an assumed speed benchmark.
- [PostgreSQL transaction isolation](https://www.postgresql.org/docs/18/transaction-iso.html). Transactions support durable state but do not replace owner checks or tested concurrency/reservation behavior. The linked documentation version is reference material, not an adopted runtime version.

Current documentation can change. Resolve/query the relevant library through Context7 at implementation time. For Privy, also use Exa to locate official sources. Record the actually adopted versions and integration conclusions.
