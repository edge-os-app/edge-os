# Triage labels

| Role | Label | Meaning |
|---|---|---|
| Needs triage | `needs-triage` | Maintainer must assess the issue. |
| Needs information | `needs-info` | Required information is missing. |
| Ready for agent | `ready-for-agent` | Accepted, sufficiently specified work for an agent. |
| Ready for human | `ready-for-human` | Work requires human participation. |
| Will not proceed | `wontfix` | Maintainer decided not to pursue it. |

A label does not grant publishing, spending or financial authority.

This mapping does not create remote labels. Their creation is a separate setup operation.
